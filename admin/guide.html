Welcome to the BLEGAB Luxury Wigs Admin Dashboard. This guide explains how to use the administration system to manage products, orders, customers, store settings, sales information, and your administrator account.

1. Getting Started

1.1 Admin Sign In

The Admin Sign In page is used to securely access the administration dashboard.

To sign in, enter:

  • Email — The email address registered to your administrator account.
  • Password — Your administrator password.
  • Admin Access Code — Your 8-digit administrator access code.

Click Sign In to access the dashboard.

Important

The Admin Access Code must contain exactly 8 digits.

If any required field is missing or the access code is invalid, the dashboard will display an error message.

2. Creating an Administrator Account

The Admin Sign Up page allows a new administrator account to be created.

You will be required to provide:

  • Full Name
  • Email Address
  • Password
  • Confirm Password
  • 8-digit Admin Access Code
  • Master Admin Secret

Password Requirements

The administrator password must:

  • Contain at least 8 characters
  • Contain at least one uppercase letter
  • Contain at least one lowercase letter
  • Contain at least one number
  • Contain at least one of these symbols: # @ * , .

The password confirmation must match the original password.

The Admin Access Code must contain exactly 8 numbers.

3. Recovering an Admin Account

If you forget your administrator password or access code, use Forgot Password or Access Code? on the Admin Sign In page.

Step 1 — Select the Recovery Option

Choose whether you want to recover:

  • Your password
  • Your admin access code

Enter the email address associated with the administrator account and click Send Recovery Link.

Step 2 — Verify Your Code

A verification code is sent to the administrator's email.

Enter the 6-digit verification code on the verification page.

Step 3 — Reset Your Credentials

After successful verification, you can create a new:

  • Administrator password, or
  • 8-digit administrator access code

For a new password, the same password requirements used during registration apply.

5. Dashboard Statistics

6. Notifications

The notification bell in the admin dashboard displays important administrative notifications.

The notification area provides:

  • Unread notification count
  • Notification list

9. Adding a Product

Click Add Product to create a new product.

The product form includes:

Product Name

Enter the name customers will see for the product.

SKU

Enter the product's SKU/reference.

Category

Select the category the product belongs to.

Price

Enter the product price.

Quantity

Enter the available stock quantity.

Product Images

Upload a main product image and additional images.

The system allows multiple product images to be uploaded.

You can:

  • Add the main image
  • Add additional images
  • Preview images
  • Remove images
  • Change/remove the main image

Product Specifications

The product form supports:

  • Length
  • Density
  • Lace Type

Examples include:

  • 22"
  • 180%
  • HD Lace

Description

Enter a short description explaining the product.

Badge

Products can have promotional/display badges such as:

Product Status

After entering the information, click Save Product.

Review:

  • Sales information

  • Notifications

Step 3 — Check Inventory

48. Tips for Managing the Store

Keep Product Information Accurate

Make sure product names, prices, stock quantities, specifications, and images are correct.

Update Stock Regularly

Low-stock and out-of-stock statuses help identify products that require inventory attention.

Keep Order Statuses Updated

Customers and store staff rely on accurate order statuses.

Use Categories Properly

Well-organized product categories make products easier to manage.

Use Filters and Search

When the store contains many products, orders, or customers, use the search and filtering tools instead of manually browsing through the entire list.

Export Important Records

Use PDF, DOC, or CSV exports when you need offline records or reports.

Protect Administrator Credentials

Do not share the administrator password, access code, or master admin secret with unauthorized users.

  • Keep passwords private.
  • Keep the 8-digit access code private.

  • Use strong passwords.
  • Sign out when finished.
  • Avoid using administrator accounts on untrusted computers.
  • Only give dashboard access to trusted personnel.

51. Troubleshooting

I cannot sign in

Check that:

  • Your email is correct.
  • Your password is correct.
  • Your access code contains exactly 8 digits.
  • Your account has been registered.

I forgot my password

Use Forgot Password or Access Code? and follow the verification process.

I forgot my access code

Use the account recovery option for the access code and follow the email verification process.

My password is rejected

Make sure the password contains:

  • At least 8 characters
  • Uppercase letter
  • Lowercase letter
  • Number
  • One of the supported symbols: # @ * , .

A product is difficult to find

Use the Products search and filtering tools.

I need to find a particular order

Use the Orders search field or filter orders by status.

I need customer information

Open the Customers section and search for the customer.

I need a report

Use the Statistics & Earnings section to generate an earnings statement in PDF or CSV format.
